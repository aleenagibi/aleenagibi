**GreenLens** — my final-year major project, now doubling as the basis for a second research paper. An agentic, carbon-aware LLM inference orchestrator: it embeds a task, predicts complexity/capability/carbon cost per candidate model, routes to the smallest model on the lowest-carbon deployment that meets the constraints, and explains the decision. Built on FAISS + Sentence-Transformers for task embedding, self-hosted inference via Ollama/vLLM, and live grid-carbon data.
